# 🚀 Steam Center Ultimate 2026 (.NET 10 Edition)

**Steam Center Ultimate** — это мощный и легкий менеджер аккаунтов Steam, разработанный для геймеров, владельцев ферм и активных пользователей. Приложение позволяет переключаться между аккаунтами в один клик без повторного ввода пароля, управлять конфигами игр и хранить учетные данные в безопасности.(нужно в тех случаях если у вас более чем 5 аккаунтов и неполучаеться через стим переключится на акк)

## 🌟 Основные возможности

### 🔄 Мгновенное переключение (Fast Switch)
* **Вход в один клик:** Забудьте про окно ввода логина и пароля. Программа автоматически завершает процессы Steam и авторизует выбранный аккаунт.
* **Автоматизация Steam Guard:** Поддержка запомненных сессий (не требует код при каждом входе, если установлена галочка "Запомнить меня").

### 📁 Управление конфигурациями (Config Sync)
* **Глобальный перенос настроек:** Возможность скопировать папку `userdata` из одного аккаунта в другой. 
* **Синхронизация CS2 и других игр:** Перенос прицелов, биндов, настроек графики и аудио между аккаунтами в пару кликов. Больше не нужно настраивать игру с нуля на новом "твинке".

### 📋 Менеджер учетных данных (Smart DB)
* **Интегрированная база данных:** Хранение логинов, паролей и привязанных электронных почт в удобном формате.
* **Умное контекстное меню (ПКМ):** Нажмите правой кнопкой мыши на аккаунт, чтобы мгновенно скопировать логин, пароль или почту в буфер обмена.
* **Динамические кнопки:** Интерфейс сам подскажет, есть ли данные в базе ("Скопировать") или их нужно внести ("Добавить").

### 🎨 Продвинутый интерфейс
* **Система "Избранное":** Закрепляйте важные аккаунты в топе списка с помощью золотой звезды.
* * **Генератор аккаунтов:** Быстрое создание заготовок для новых аккаунтов с автоматическим сохранением в базу.

## 🛠 Технологический стек
* **Платформа:** .NET 10.0-windows
* **Интерфейс:** WPF (Windows Presentation Foundation)
* **Язык:** C# 14.0
* **Взаимодействие со Steam:** Прямая правка реестра Windows (`RegistryKey`) и манипуляция файлами конфигурации VDF.
